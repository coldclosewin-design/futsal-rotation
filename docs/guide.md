# FC EXICAN 운영 허브 사용 가이드

이 문서는 두 부분입니다. 팀원은 **팀원 편**만 읽으면 됩니다. 회장은 **회장 편**까지 읽습니다.
주소: https://coldclosewin-design.github.io/futsal-rotation/

## 시작하기 (모두)

### 처음 한 번만
1. 카톡 공지의 링크를 엽니다.
2. **팀 PIN**을 입력합니다. PIN은 회장이 개인톡으로 알려 줍니다. 한 번 입력하면 그 기기에서는 다시 묻지 않습니다.
3. 투표 화면에 들어가면 **내 이름을 선택하세요** 창이 뜹니다. 내 이름을 누릅니다. 잘못 골랐으면 화면 위 "내 이름: ○○○" 옆 **변경**을 누릅니다.
4. 카톡 안에서 열어도 되지만 자주 쓰려면 홈 화면에 추가해 두세요. 아이폰은 사파리 공유 → 홈 화면에 추가, 안드로이드는 크롬 메뉴 → 홈 화면에 추가.

### 화면 구성
- 아래쪽 탭 5개: **홈 · 투표 · 매칭 · 배정표 · 장부**
- **더보기**(점 세 개) 안: **내 현황 · 회칙 · 도움말 · 관리**(관리는 회장용)
- 보드가 있는 화면은 위에서 아래로 같은 순서입니다. 검은 **보드**(이 화면의 핵심 숫자와 상태) → 흰 **패널**(내가 할 일) → **목록**(참고 정보)
- 숫자 옆에 **초록 점**이 켜져 있으면 "지금 할 일이 있다" 또는 "최근에 바뀌었다"는 뜻입니다. 점이 없으면 손댈 일이 없습니다.

## 팀원 편

### 1. 홈: 이번 주 한눈에 보기
- 보드에 이번 주 토요일 날짜와 **D-day**, 투표 상태(진행 중/마감), 매치 상태(확정/없음)가 보입니다.
- 확정된 매치가 있으면 보드 아래 줄에 날짜·시간·구장·포맷·구장비가 뜹니다.
- 아래 카드에서 **이번 주 투표**(참석 인원, 투표하기 버튼), **매칭 후보**(상위 후보), **배정표 · 장부 · 내 현황** 바로가기를 씁니다.
- **링크 복사**와 **후보 공유**는 카톡에 붙여넣을 문구를 복사합니다. 회장이 아니어도 쓸 수 있습니다.

### 2. 참석 투표 (매주 가장 중요)
- 투표는 **매주 일요일 13:00 이후 자동으로 열리고 월요일 13:00에 마감**됩니다. 회장이 카톡에 링크를 올립니다.
- 투표 제목은 항상 날짜가 먼저입니다(예: "10/24(토) 정기 풋살"). 관리 → 투표 탭에서도 날짜가 크게, 상태(진행 중·마감·취소)는 칩으로 보입니다.
- **투표** 탭 → 보드에서 경기 날짜·현재 참석 인원·마감까지 남은 시간·가능한 포맷(5v5/6v6)을 확인합니다.
- 보드 아래 **경기 일시** 줄에 실제 경기 시간·구장·상대팀이 보입니다. 아직 매치가 안 잡혔으면 "매치 미확정"으로 표시되고, 확정되면 자동으로 바뀝니다. 누르면 매칭 탭의 확정 매치 상세로 갑니다.
- **참석** 또는 **불참**을 누르면 바로 저장됩니다. 마감 전에는 다시 눌러 바꿀 수 있습니다.
- 아래 **투표 현황**에서 누가 참석·불참·미투표인지 보입니다. 참석은 진한 테두리 칩, 불참은 회색 점선 칩, 미투표는 초록 점이 켜진 칩입니다.
- **마감까지 투표하지 않으면 회칙에 따라 벌금 5,000원**이 장부에 자동 기록됩니다. 마감 뒤에 투표해도 "지각 투표"로 벌금 대상입니다.
- 참석에 투표하고 개인 사유로 안 나오면 벌금 10,000원입니다(회칙). 부고 등 애사는 회장에게 말하면 면제됩니다.
- 공휴일·이벤트 경기처럼 토요일이 아닌 경기는 **특별 투표**로 따로 올라옵니다. 투표 화면 보드 맨 위의 전환 칩(예: "10/17 토 경기 · 마감 | 10/22 목 특별 매치 · 진행 중")을 눌러 각각 응답합니다. "벌금 없음" 표시가 있는 투표는 안 해도 벌금이 없습니다.

### 3. 매칭 후보 보고 추천하기
- **매칭** 탭에는 모두의풋살 카페 4개 게시판(성남/하남, 서울북동, 서울남동, 남양주/구리)에서 **매시간 자동으로 모은 토요일 오전 상대팀 모집글**이 점수순으로 보입니다. 오전 8시 시작이 가장 높고 7시, 9시, 10시 순입니다.
- 보드의 "새 후보"가 켜져 있으면 최근 24시간 안에 새 글이 들어온 것입니다.
- 위 패널에서 지역 칩, **토요일만 · 오전만 · 포맷 · 마감 포함 · 미분류 보기**로 거릅니다. "미분류"는 제목에서 날짜나 시간을 읽지 못한 글이니 제목을 직접 확인하세요.
- 마음에 드는 후보는 카드의 **엄지(추천)** 버튼을 누릅니다. 추천 수와 누가 눌렀는지 회장이 보고 연락 순서를 정합니다.
- 카드 제목을 누르면 카페 글이 열립니다(카페는 네이버 로그인이 필요할 수 있습니다).
- 회장이 상대팀과 합의하면 카드에 **확정** 배지가 붙고 홈 보드에 확정 매치로 뜹니다.
- 게시판에서 밀려나 수집기가 3일 넘게 보지 못한 글은 목록에서 자동으로 빠집니다. 확정된 매치는 목록 맨 위 **확정 매치**에 카페 글 링크와 함께 남습니다.
- 확정 매치 아래 **지난 경기**에서 최근 경기 결과(스코어·참석 인원)를 볼 수 있습니다.

### 4. 경기 당일 배정표
- 키퍼(GK)와 휴식 순서는 회장이 **배정표**에서 만들어 카톡에 올립니다. 보통 8쿼터 기준이며, 한 사람의 휴식과 키퍼가 몰리지 않게 자동으로 고르게 배치합니다.
- 직접 만들어 볼 수도 있습니다. **배정표** 탭 → 참가자 체크 → 포맷 선택 → **배정표 생성** → 마음에 안 들면 **다시 섞기** → **카톡에 복사**. 저장(**이번 매치에 저장**)은 회장만 됩니다.
- 늦게 오거나 일찍 가는 사람은 이름 옆에서 참가 구간(몇 쿼터부터·까지)을 정하면 그 구간 안에서만 배정됩니다.

### 5. 간식 청구 (내 돈으로 샀을 때)
- 회칙상 공식 경기 간식은 물 2 + 음료 1(여름은 음료 2)이며 회비로 삽니다. 내가 먼저 사 왔다면 청구합니다.
- **장부** 탭 → 첫 패널의 **간식 청구** → 매치 선택(최근 4주), 구매 금액, 구매 품목(예: 물2 음료1) → **청구 제출**.
- 회장이 승인하면 장부에 "팀이 나에게 줄 돈"으로 기록되고, 회장이 돌려줍니다. 장부의 **내 간식 청구**에서 승인/거절 상태를 볼 수 있습니다.

### 6. 회비·벌금과 내 현황
- 회비는 **매월 1일 30,000원**이고, 매월 자동으로 장부에 "내야 할 돈"으로 올라갑니다. 납부는 지금처럼 **카카오 정산 또는 회장 계좌로** 보냅니다. 회장이 입금을 확인해 정산 처리하면 미납이 사라집니다.
- **더보기 → 내 현황**: 보드에 **이번 달 미납액**(있으면 초록 점), 최근 12주 참석률, 투표 참여율, 키퍼 누적. 아래에 이번 달 납부 내역(회비·벌금·면제·환급·정산 완료), **전 기간 미정산**, 벌금 이력(최근 20건), 배정 누적(키퍼·휴식 횟수)이 있습니다.
- **장부** 탭: 보드에 팀 잔액, 이번 달 미납 합계와 미납자 수, 이번 달 지출. **멤버별 이번 달** 표에서 이름을 누르면 상세 항목이 펼쳐집니다. **내 항목만**을 켜면 내 행만 보입니다.
- 부상으로 4주 이상 못 뛰면 회장에게 진단서·진료 내역을 보내세요. 그 기간은 회비가 50% 면제로 자동 반영됩니다.

### 7. 회칙
- **더보기 → 회칙**: 회비·벌금 기준을 한눈에, 그 아래 회칙 전문을 볼 수 있습니다.
- 회칙 개정 제안은 매월 24일까지 회장 개인톡으로.

### 자주 묻는 질문 (팀원)
- **이름을 잘못 골랐어요.** 투표 화면 위 "내 이름" 옆 **변경**을 누르세요. 이전 이름(○○○)으로 한 투표는 그대로 남습니다. 잘못 골랐다면 회장에게 알려주세요.
- **PIN을 모르겠어요 / 틀렸대요.** 회장에게 개인톡으로 물어보세요. 공개 방에 PIN을 올리지 마세요.
- **투표를 바꾸고 싶어요.** 월요일 13:00 전이면 다른 버튼을 누르면 됩니다. 마감 후에는 회장에게 말하세요.
- **참석 투표했는데 못 가게 됐어요.** 바로 회장에게 말하세요. 사유에 따라 회장이 급불참 벌금 여부를 정합니다.
- **카톡 안에서 화면이 이상해요.** 오른쪽 위 메뉴에서 "다른 브라우저로 열기"를 쓰거나, 링크를 사파리/크롬에 붙여넣으세요.
- **"데모 데이터입니다"라고 떠요.** 주소 끝에 ?demo=1이 붙은 체험용 화면입니다. 공지의 원래 링크로 다시 들어가세요.
- **내 폰에서만 이름이 저장되나요?** 네. 다른 폰이나 PC에서는 PIN과 이름을 다시 고릅니다.

## 회장 편

### 0. 회장 로그인
- 팀 PIN으로 들어온 상태에서 화면 위 **회장 로그인** → 회장 비밀번호. 로그인하면 각 화면에 **회장 도구** 패널과 상태 버튼이 나타납니다. **로그아웃**하면 다시 팀 상태로 돌아갑니다.
- 수정 권한은 서버(Supabase RLS)가 검사합니다. 팀 PIN으로는 버튼이 보여도 저장되지 않습니다.
- 회장 비밀번호는 PIN과 마찬가지로 공개 방에 올리지 않습니다.

### 1. 한 주 운영 순서
- **일요일 13:00 이후** 투표가 자동 생성됨 → 홈에서 링크 복사 → 카톡 공지
- **월요일 13:00** 투표 자동 마감, 미투표 벌금 자동 기록 → 참석 인원과 포맷 확인
- **월~금** 매칭 후보 확인 → 카페 글에서 연락처 확인 → 문자 → 상태 기록 → 확정
- **토요일** 배정표 생성 → 카톡 공유 → 경기
- **경기 후** 출석·지각·급불참 기록 → 구장비·간식 정리
- **월초** 회비 자동 생성 확인 → 입금 정산 처리

### 2. 일요일: 투표 링크 공유
- 매시간 도는 자동 작업(GitHub Actions)이 일요일 13:00 이후 첫 실행에서 다음 토요일 투표를 만듭니다. 직접 만들 필요가 없습니다.
- 13:00 정각에 생기지는 않습니다. GitHub 스케줄은 혼잡하면 늦게 돌아서 보통 13:00~14:00 사이, 최대 1시간쯤 늦을 수 있습니다.
- 홈 **이번 주 투표** 카드의 **링크 복사**를 눌러 카톡에 붙여넣습니다. 문구에 날짜와 마감 시각이 들어 있습니다.
- 투표가 보이지 않으면(자동 작업이 아직 안 돌았을 때) **투표** 탭 회장 도구의 **투표 만들기**에서 다음 토요일 날짜로 만들면 됩니다. 같은 날짜가 이미 있으면 "이미 있습니다"가 뜹니다.
- 그 날짜 투표를 전에 **취소**해 둔 상태였다면 자동 작업은 새로 만들지 않습니다(취소는 삭제가 아니라 숨김). 이때는 **투표 만들기**로 같은 날짜를 다시 만들면 취소가 풀리면서 다시 열리고, **관리 → 투표** 탭의 **투표 취소** 행의 **해제**를 눌러도 됩니다.
- **투표 취소** 행의 **취소**를 누르면 기록 유지와 자동 생성 제외 안내를 확인한 뒤 취소합니다. 취소 후 투표 화면에 남는 **관리 → 투표** 복구 링크에서 **투표 취소** 행의 **해제**를 누르면 즉시 되돌릴 수 있습니다. 확인창의 **닫기**는 아무것도 바꾸지 않습니다.
- **취소와 삭제의 차이**: 취소는 "이번 경기 없음"이라 기록(투표·벌금)을 남긴 채 숨깁니다. 삭제는 잘못 만든 투표를 투표 기록·벌금 기록까지 지우며 되돌릴 수 없습니다(확정 매치는 남고 투표 연결만 풀립니다). 투표 탭 회장 도구의 **관리 → 투표**나 관리 → 투표 탭의 **투표 삭제**로 합니다. 확인 창에 함께 지워지는 건수가 나옵니다.
- 삭제한 날짜가 자동 생성 창(일요일 13:00~월요일 13:00) 안이면 다음 자동 작업이 같은 날짜 투표를 다시 만듭니다. 이미 입금 정산 처리된 벌금이 연결된 투표만 삭제가 거부되니 그때는 취소를 쓰세요.

### 3. 월요일: 마감 확인
- 13:00 이후 자동 작업이 투표를 마감 처리하고 **미투표자에게 벌금 5,000원**을 장부에 기록합니다. 보통 14:00 전에 반영됩니다.
- **투표** 탭 보드에서 참석 인원과 가능 포맷(5v5는 5명 이상, 6v6은 6명 이상 참석)을 확인합니다. 아래 **투표 현황**에서 미투표자 이름을 봅니다.
- 급한 사정으로 마감 후 투표하는 사람이 있으면 그대로 두면 됩니다. 늦은 투표는 "지각"으로 표시되고 벌금은 이미 기록되어 있으니, 봐주기로 했다면 장부에서 **조정** 항목으로 상쇄합니다(9. 참고).
- 인원이 부족해 매칭이 어려우면 회칙대로 플랩 지원(인당 월 1회)을 안내하고, 경기 후 장부에 **플랩 지원**으로 기록합니다.

### 4. 주중: 상대팀 매칭
- **매칭** 탭의 후보는 매시간 자동으로 갱신됩니다. 기본 필터(토요일·오전·마감 제외)에서 점수가 높은 순서로 보고, 팀원 추천(엄지) 수와 "반응한 팀원"을 참고합니다.
- 보드의 **마지막 수집**이 '12분 전'처럼 세 시간 안이면 수집기가 정상입니다. '지연'이 붙거나 '확인 불가'면 GitHub Actions를 확인합니다(12절).
- 보드 아래 **이번 주 토요일** 줄은 필터와 무관한 전체 매물 수입니다. '매물 1건 · 오전 0건'인데 목록이 비어 있으면 고장이 아니라 오전 글이 없는 것입니다. 매물은 보통 수~금에 올라옵니다.
- 후보 카드 제목을 눌러 카페 글을 열고 **본문에서 연락처(010)와 구장비 조건을 확인**합니다. 본문은 자동으로 가져올 수 없어서 이 단계만 수동입니다.
- 회장 로그인 상태에서는 카드 아래 회장 패널에 **연락처 · 구장비(원) · 메모 · 우선순위** 입력칸이 있습니다. 연락처를 넣고 **저장**합니다.
- **문자 문구 미리보기**를 보고 **문자 문구 복사** 또는 **문자 앱 열기**(폰에서는 문자 앱이 바로 열림)로 보냅니다. 문구는 팀 소개·날짜·시간·구장·인원·포맷이 자동으로 채워집니다.
- **연락 상태 버튼**은 누르는 즉시 저장됩니다: **미연락 → 문자 보냄 → 답장 옴 → 확정 / 거절·불발**. 잘못 눌렀으면 **미연락**으로 되돌립니다. 거절·불발은 점선 버튼으로 아래에 따로 있습니다.
- 상대와 합의되면 **확정** → **매치 등록** 창이 열립니다. 경기 날짜·시작·종료 시각·구장·상대팀·포맷·구장비를 확인하고 **매치 등록**을 누릅니다. **구장비를 장부에 바로 기록(팀 지출)**은 기본 켜짐이며, 체크한 경우 구장비가 장부에 음수 팀 지출로 기록됩니다. 구장비가 0원이면 체크할 수 없습니다. 실제 이체는 직접 합니다.
- 확정한 매치는 매칭 탭 맨 위 **확정 매치** 섹션에 보입니다(카페 글·관리 바로가기). 연락 상태를 바꾼 글은 3일 만료 규칙에서 제외되니, 불발이면 **거절·불발**로 바꿔 두세요.
- 같은 매치의 구장비 중복 기록은 자동 거부됩니다. 체크를 끄고 등록했거나 장부 기록 실패 안내가 뜨면 **관리 → 매치 → 구장비 기록**에서 추가할 수 있습니다. 장부 기록이 실패해도 등록한 매치는 남습니다.

### 5. 공휴일·이벤트 경기 (특별 투표)
- **투표** 탭 회장 도구 또는 **관리 → 투표** 탭의 **투표 만들기**: 날짜(아무 날짜), 제목(예: 개천절 특별 매치), 마감 시각(기본은 전날 13:00), **미투표 벌금 적용** 체크(토요일이면 기본 켜짐, 아니면 꺼짐).
- 만들면 투표 화면 보드 위에 전환 칩이 생기고 팀원이 각각 응답합니다. 홈에는 "특별 투표 N개" 행이 추가됩니다.
- 벌금 적용을 끈 투표는 미투표자가 있어도 벌금이 기록되지 않습니다.
- 취소할 때는 **투표 취소** 행의 **취소**를 누릅니다. 점선 단독 버튼은 **투표 삭제**입니다. 취소된 투표는 벌금 대상이 아닙니다.
- 투표 취소는 삭제가 아니라 **숨김**입니다. 팀원 화면에서는 사라지지만 **관리 → 투표** 탭에는 "취소"로 남아 있고, **투표 취소** 행의 **해제**를 누르거나 같은 날짜로 **투표 만들기**를 하면 취소가 풀리면서 다시 열립니다(제목·마감·벌금 설정은 새로 입력한 값으로 바뀝니다).

### 6. 토요일: 배정표
- **배정표** 탭 → **이번 주 참석자 불러오기**: 이번 주 투표의 참석자가 자동으로 체크됩니다. 현장에서 바뀐 사람은 체크를 고칩니다.
- 늦게 오는 사람·일찍 가는 사람은 참가 구간을 정합니다. 그 사람은 그 구간 안에서만 뛰고, 조기 퇴장자는 필드 위주로 배치됩니다.
- 포맷(5v5/6v6)을 고르고 **배정표 생성**. 결과표에서 키퍼 칸은 검정, 휴식 칸은 흐리게 표시됩니다. 사람별 키퍼·휴식 횟수가 고르고, 한 사람의 휴식이 앞뒤로 몰리지 않도록 자동 조정됩니다. 아래 "주의"가 뜨면 읽어 보고 **다시 섞기**를 누릅니다.
- **카톡에 복사** → 카톡방에 붙여넣기. **이번 매치에 저장**을 누르면 각 팀원의 키퍼·휴식 기록이 **내 현황**에 누적됩니다.

### 7. 경기 후: 출석과 벌금
- **관리** 탭(더보기 안) → **매치** 탭 → 해당 매치의 **출석 기록**: 사람별로 **출석 · 지각 · 경기 후 도착 · 급불참 · 사유 불참**을 고르고 **출석 저장**. 경기일이 오늘이거나 지났으면 예정 상태에서도 입력할 수 있습니다. 저장 후 패널은 열린 채이며 경기 상태는 그대로입니다.
- **출석 벌금 생성**(점선 버튼)을 누르면 지각 10,000원, 경기 후 도착 30,000원, 급불참 10,000원이 회칙대로 장부에 기록됩니다. "사유 불참"은 벌금이 없습니다. 같은 매치에 두 번 눌러도 중복 기록되지 않습니다.
- 출석 기록 → 벌금 생성 후, 끝난 경기의 상태를 **경기 완료**로 바꾸고 **매치 저장**을 누릅니다. 스코어를 알면 우리·상대 점수를 함께 넣고, 모르면 둘 다 비워 둡니다. 한쪽만 입력할 수 없습니다. **매칭 → 지난 경기**에는 점수가 없으면 **스코어 미입력**으로 보입니다.
- 회장이 매치를 성사시킨 주에는 **회장 면제 기록**을 누르면 회비 7,500원(월 회비의 1/4)이 면제로 기록됩니다.
- 관리 보드의 **출석 미입력**이 켜져 있으면 완료 매치 중 출석을 아직 안 넣은 것이 있다는 뜻입니다.

### 8. 간식 청구 승인
- 관리 보드의 **대기 청구**가 켜지면 팀원이 청구를 올린 것입니다.
- **장부** 탭 → **회장 도구** → **간식 청구 승인**: 매치·금액·품목을 보고 **승인** 또는 **거절**. 승인하면 장부에 팀 지출과 "청구자에게 줄 돈"이 함께 기록됩니다. 실제 송금은 직접 하고, 보냈으면 그 사람 행에서 정산 처리합니다.

### 9. 월초: 회비와 정산
- 2026년 11월부터 매월 1일 활동 멤버 전원에게 회비 30,000원이 자동으로 올라갑니다. 그 전 달까지는 지금처럼 카톡 정산으로 마감합니다.
- 부상 기간이 등록된 멤버는 그 달 회비의 50%가 **면제**로 자동 기록됩니다. 부상 기간은 **관리 → 멤버** 편집에서 넣습니다.
- 입금을 확인하면 **장부** → **멤버별 이번 달** → 이름을 눌러 펼친 뒤 항목을 체크하고 **선택 정산**, 또는 **○○○ 전부 정산**. 정산된 항목은 미납에서 빠지고 팀 잔액에 들어갑니다.
- 수동 기록이 필요하면 **회장 도구 → 기록 추가**: 종류(지각 · 경기 후 도착 · 급불참 · 구장비 · 플랩 지원 · 입금 · 조정), 대상 멤버, 금액, 날짜, 메모 → **기록 저장**. 벌금을 깎아 줄 때는 자동 기록을 지우지 말고 **조정**으로 반대 금액을 넣어 상쇄합니다.
- **팀 지출**(회장 도구)에는 구장비·간식 외 지출을 기록합니다.

### 10. 멤버 관리
- **관리 → 멤버** 탭: **새 멤버** 또는 이름 옆 **편집** 버튼으로 편집. 이름, 활동 여부, 회장 여부, 가입일, 부상 기간, 연락처, 계좌.
- 표에 열을 더 두고 싶으면 **열 관리 → 새 열 이름 → 추가**(예: 포지션, 등번호). 모든 멤버에게 빈 값으로 생기고, 값은 멤버 편집에서 넣습니다. **열 관리**에서 해당 열의 **삭제**를 누르고 확인하면 그 열과 모든 멤버의 값이 지워집니다. 기본 열(이름·활동·회장·가입일·부상·연락처·계좌)은 지울 수 없습니다.
- 탈퇴자는 삭제하지 말고 **활동**을 끄세요. 기록은 남고 투표·회비 대상에서는 빠집니다.
- 표는 좌우로 밀어 연락처와 계좌를 봅니다. 이 정보는 팀 PIN으로 로그인한 사람만 볼 수 있습니다.

### 11. 자동으로 되는 것 / 안 되는 것
- 자동: 투표 생성(일 13:00 이후), 투표 마감과 미투표 벌금(월 13:00 이후), 카페 후보 수집(매시간), 월 회비와 부상 면제(매월 1일), 확정 매치의 구장비 장부 기록
- 수동(회장): 카페 본문의 연락처 확인, 문자 발송(앱만 열어 줌), 구장비·환급 이체, 출석 입력과 출석 벌금 생성, 간식 승인, 입금 정산 처리
- 자동 작업은 GitHub 저장소의 Actions 탭에서 돌아갑니다. 60일 동안 저장소에 아무 변경이 없으면 GitHub가 자동 작업을 꺼 버리므로, 그때는 Actions 탭에서 다시 켭니다.

### 12. 문제가 생겼을 때
- **PIN 또는 회장 비밀번호 분실**: Supabase 대시보드 → Authentication → Users → 해당 계정(team / admin) → 비밀번호 재설정. 새 PIN은 팀원에게 개인톡으로 전달합니다. 상세는 README의 "운영 절차".
- **투표가 안 생겼다**: 먼저 **관리 → 투표** 탭에 그 날짜가 "취소"로 남아 있는지 봅니다. 있으면 **투표 취소** 행의 **해제**(또는 같은 날짜로 **투표 만들기**). 없으면 Actions 탭에서 cron 실행 기록을 확인하고 필요하면 "Run workflow"로 수동 실행. 급하면 **투표 만들기**로 직접 생성.
- **후보가 안 들어온다**: 같은 cron 로그에서 네이버 응답 오류를 확인합니다. 카페 글 형식이 바뀌면 "미분류"가 늘어납니다.
- **벌금이 잘못 잡혔다**: 자동 기록은 지우지 말고 **조정**으로 상쇄합니다. 이력이 남아 나중에 설명하기 쉽습니다.
- **구장비가 두 번 잡혔다**: 장부에서 중복 행을 확인하고 **조정**으로 한 건을 상쇄합니다.
- **화면이 예전 모양이다**: 새로고침 한 번. 카톡 인앱 브라우저는 캐시를 오래 들고 있습니다.
- **백업**: Supabase 대시보드 → Table Editor에서 CSV 내보내기. 분기마다 한 번 권장.
