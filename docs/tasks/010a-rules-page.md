## 상세 요구사항

### 1. 회칙 원문 (`docs/rules.md`에 이 내용을 그대로 저장)
```
# Exican 모임 운영 안

## 1. 회비
- 3만원
- 매월 1일 납부를 원칙 (카카오 정산)
- 계좌: 회장에게 문의

## 2. 경기 운영
- 매주 토요일 오전 진행
- 회비 사용은 공식 일정에 한하여 구장비와 간단한 간식을 포함한 식음료 구매 시에만 허용
  (단, 모든 인원이 참석할 경우 이외 목적(사우나, 회식 등)에 대하여 운영위원장이 승인한다면 회비 사용 가능)
- 경기 시작 15분 전 도착 필수
- 공식 경기가 있는 주에는 운영위원장 주도 하에 경기를 수립 및 진행하고 회비 면제의 특혜가 주어짐
  (운영위원장: 공식 경기 일정 수립 / 구장 확정 / 상대팀 매칭 등)
- 매칭이 불가한 주(인원 미달, 상대팀 섭외 실패 등)는 참석자들 희망 시 플랩 비용 지원 (인당 월 1회 한)

## 3. 부상자 회비 면제 (50%)
- 부상자의 경우 회비 50% 면제 혜택이 주어짐
- 기준: 풋살을 진행하지 못할 정도의 신체 부상으로 인해 4주 이상 경기를 뛰지 못하는 경우
- 증빙: 별도 진단서 혹은 병원 진료 내역 및 처방전 등

## 4. 벌금 규정
- 지각: 경기 시간 15분 전까지 경기장에 도착하지 못할 경우 벌금 1만원 부과 (단, 경기 시작 이후 도착했을 경우에는 벌금 3만원)
- 투표: 기한 내 투표 미참여 시 벌금 5,000원 (투표 등록: 일요일 13시 이전 / 투표 마감: 월요일 13시)
- 참석 투표 후 급불참
  - 참석 투표 후 갑작스런 애사(부고 등)로 인한 불참석은 인용할 수 있는 범위(친인척, 가까운 지인) 내에서 별도의 벌금 없이 수용 (해당 사유로 인해 게임 진행 불가 시 내부적으로 토의 후 진행 여부 결정)
  - 참석 투표 후 개인적인 사유로 인한 불참석은 벌금 1만원 부과 (게임 진행 가능 여부 상관없음)

## 5. 회칙의 신설 및 변경
- 제안: 당월 24일 24:00까지 운영위원장 개인톡으로 제안 (선택지 포함하여 작성 후 제출)
- 투표: 당월 25일 오전 운영위원장 주관 익명투표 진행 (기한: ~ 말일 24:00)
- 시행: 찬성 투표 수 / 전체 투표 수 > 0.7인 경우 진행 (소수점 둘째 자리에서 반올림)
- 단, 운영위원장 판단 하에 급한 건은 상기 회칙 변경 방식과 관계없이 익명투표 진행 가능 (운영위원장이 주관하는 투표임을 공지)
  (유니폼/축구용품(키퍼 장갑) 구매/회식 진행 등)

## 6. 현장 배치 자동화 프로그램 (전준영 회원 재능기부)
- 배정표: rotation.html
```

### 2. `rules.html`
- 공용 내비 `renderNav("rules")`. 인증 불필요(정적, 공개).
- 상단 "벌금·회비 한눈에" 표: 항목 / 금액 / 기준. 금액은 `EXICAN_CONFIG.FINES`, `DUES_MONTHLY`, `INJURY_EXEMPT_RATE`로 계산해 `formatWon`으로 표시 (하드코딩 금지). 항목: 월 회비, 부상자 면제 후 회비, 투표 미참여, 참석 후 급불참, 지각(15분 전 미도착), 경기 시작 후 도착.
- 본문: `docs/rules.md`를 `fetch`로 읽어 아주 작은 마크다운 변환기(제목 `#`/`##`, 불릿 `-`, 들여쓴 하위 불릿, 빈 줄 → 문단)로 HTML 렌더. 외부 라이브러리 금지. `escapeHtml` 적용 후 변환. `rotation.html` 문자열은 링크로.
- 하단: "회칙 개정 제안은 매월 24일까지 운영위원장에게" 안내 박스.
