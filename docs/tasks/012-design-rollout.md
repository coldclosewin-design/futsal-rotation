# [012] 디자인 시스템 "구장 전광판" 전 페이지 적용

- 브랜치: `codex/012-design-rollout`
- 의존: v2.0.0 + 디자인 1차 커밋(main의 `styles.css`, `js/ui.js`, `index.html`)
- 예상 규모: L

## 배경
홈(`index.html`)에 새 디자인 시스템이 적용됐습니다. 토큰·공용 셸(하단 탭바/데스크톱 레일)·간유리 패널·버튼·입력·모달·표의
기본 스타일은 `styles.css`가 이미 전 페이지에 입히고 있으나, 각 페이지의 **구성**(무엇을 보드에 올리고, 무엇을 행 목록으로,
무엇을 점등할지)은 아직 예전 그대로입니다. 이 발주서는 나머지 7개 페이지를 같은 세계로 옮깁니다.
디자인 규칙 전문은 `DESIGN.md`, 제품 맥락은 `PRODUCT.md`. **새 색·새 반경·새 글자 크기를 만들지 않습니다.** 필요한 건 전부 `styles.css`의 토큰과 컴포넌트로 조립합니다.

## 목표
- 모든 페이지가 같은 문법을 쓴다: 페이지 상단 **보드**(어두운 띠, 이 화면의 핵심 숫자·상태) → **간유리 패널**(작업) → **행 목록**(부가 정보·이동).
- 강조색(점등)은 "지금 할 일·바뀐 것"에만 나타난다.
- 이모지·인라인 색상·파란색 잔재가 사라진다.

## 변경 파일
- `vote.html`, `matches.html`, `ledger.html`, `rotation.html`, `member.html`, `admin.html`, `rules.html`
- `styles.css` — 페이지별 보정 섹션만 수정(토큰·공용 컴포넌트 정의 블록은 수정 금지; 새 클래스가 필요하면 "페이지별 보정" 섹션에 추가)
- `js/ui.js` — `ICONS`에 아이콘 추가만 허용(기존 아이콘·`renderNav` 수정 금지)
- `README.md` — 화면 설명 문구 갱신

## 변경 금지
- `index.html`(홈은 완료), `js/*.js`(ui.js의 ICONS 추가 제외), `scripts/*`, `supabase/*`, `test/*`(스냅샷 성격 테스트가 깨지면 그 테스트만 보정하고 PR에 명시), `DESIGN.md`, `PRODUCT.md`

## 공통 규칙 (모든 페이지)
1. **보드**: `<section class="board">` 한 개를 `<h1>` 바로 아래에. 왼쪽 `.label` + 제목, 오른쪽 `.display` 숫자 1개(그 화면의 핵심 수치), 아래 `.segments`(2~3칸) 또는 `.board-lines`. 디스플레이 숫자는 페이지당 1개뿐.
2. **점등**: `.segment.is-lit` 또는 `.lit-dot` 클래스는 "사용자가 지금 해야 할 일" 또는 "최근 24시간 내 바뀐 것"에만. 정적 상태(마감됨, 확정됨)는 점등하지 않는다.
3. **행 목록**: 링크·요약 목록은 `.rows > .row`(라벨 왼쪽, 숫자/동작 오른쪽)로. 카드 안에 카드를 넣지 않는다.
4. **파괴적 동작**(투표 취소, 벌금 생성, 거절, 삭제, 정산 해제)은 `.btn-destructive` 클래스로, 다른 버튼과 같은 줄에 두지 않고 아래에 혼자 둔다.
5. **아이콘**: `icon(name, size)`로만. 이모지·유니코드 기호(→, ✓, ⚠️) 금지. 필요한 아이콘이 없으면 `ICONS`에 같은 스트로크 규격(24 그리드, 1.75px)으로 추가.
6. **인라인 `style=` 금지**, 색상 hex 직접 사용 금지(토큰 변수만).
7. 375px에서 가로 넘침 없음, 터치 44px, 콘솔 에러 없음. 데모(`?demo=1`)와 라이브 모두 동일 구조.

## 페이지별 요구사항

### vote.html
- 보드: 라벨 "이번 주 투표", 제목 "10/17(토) 경기", 디스플레이 = 참석 인원(`attendanceSummary.count`). 세그먼트 3칸: 상태(진행 중이면 **점등**), 마감까지 남은 시간, 가능 포맷("5v5 · 6v6" / "인원 부족").
- 패널 1(투표): 내 이름 뱃지 + [참석][불참] 64px 버튼. 마감 후 안내 문구는 라벨 크기.
- 패널 2(현황): 참석/불참/미투표 칩 목록. **미투표 칩에만** `.lit-dot`(투표 진행 중일 때).
- 회장 도구: 행 목록으로 "다음 투표 생성"(`.row-action`), "투표 취소"는 `.btn-destructive`로 패널 맨 아래 단독.

### matches.html
- 보드: 라벨 "매칭 후보", 제목 "이번 주 토요일 오전", 디스플레이 = 기본 필터 후보 수. 세그먼트: 미분류 수, 마감 포함 여부, 내 👍 수. **새 후보(`first_seen_at`이 24시간 이내) 수가 1 이상이면 그 세그먼트 점등**.
- 필터 바: 현재 구조 유지하되 패널 안 칩은 `.chip` 스타일(선택 시 `aria-pressed` → 잉크 채움).
- 후보 카드: 제목(링크) 위에 **순위 숫자**를 `.row-figure`로, 배지 줄, 메타 줄(작성·댓글·조회), 👍 버튼(`icon("thumb")`). 새 후보 카드에는 제목 옆 `.lit-dot`.
- 회장 패널: 상태 버튼 5개 유지(즉시 저장), "거절"만 `.btn-destructive`로 분리. 문자 복사/문자 앱 열기는 `.home-actions` 2열.
- 확정 모달: 기존 클래스 `.modal`/`.match-confirm` 그대로(스타일은 공용).

### ledger.html
- 보드: 라벨 "장부 · 2026-10"(월 이동 ◀▶는 보드 오른쪽 위 작은 버튼), 디스플레이 = **팀 잔액**. 세그먼트: 이번 달 미납 합계(미납자 있으면 **점등**), 미납자 수, 이번 달 지출.
- 기존 타일 3개(`.ledger-tiles`) 제거(보드가 대체).
- 멤버별 표: 표 유지하되 미납 셀은 `.lit-dot` + 굵게(이미 공용 스타일에 있음). 행 펼침 유지.
- 팀 지출·간식 청구·회장 도구는 각각 패널. "선택 정산"은 primary, "전부 정산"은 secondary, 정산 해제/거절은 `.btn-destructive`.

### rotation.html
- 보드: 라벨 "키퍼·휴식 배정", 제목 = 매치 날짜(연동 시) 또는 "오늘", 디스플레이 = 선택된 참가자 수(체크박스 변경 시 갱신). 세그먼트: 포맷(5v5/6v6), 최소 인원 충족 여부(미충족이면 점등 아님, 흐리게 `.is-dim`), 연동 상태.
- 인라인 `style=` 7곳 제거 → `.meta`/`.label`/`.hidden` 클래스로. `showFatal`의 `cssText`도 클래스(`.fatal`)로 옮기고 스타일은 styles.css 페이지 보정 섹션에.
- 참가자 그리드·포맷 선택·결과표는 공용 스타일 유지. 결과표 GK 셀은 잉크 채움(흰 글자), 휴식 셀은 흐린 잉크.
- 버튼 순서: [배정표 생성](primary) → 결과 → [다시 섞기](secondary) [카톡에 복사](primary) 2열 → 회장 저장 행.

### member.html
- 보드: 라벨 "내 현황", 제목 = 멤버 이름, 디스플레이 = **이번 달 미납액**(0이면 "0원", 음수면 "받을 돈 N원"), 미납이 있으면 세그먼트 점등. 세그먼트: 최근 12주 참석률, 투표 참여율, 키퍼 누적.
- 벌금 이력·배정 누적은 행 목록(`.rows`), 날짜 왼쪽·금액 오른쪽 `.row-figure`.
- "다른 멤버 보기" 셀렉트는 보드 아래 한 줄.

### admin.html
- 보드: 라벨 "팀 관리", 제목 "회장 도구", 디스플레이 = 다가오는 매치까지 D-day(없으면 "—"). 세그먼트: 대기 중 간식 청구 수(1 이상이면 점등), 출석 미입력 완료 매치 수(1 이상이면 점등), 활동 멤버 수.
- 탭 3개(`.operations-tabs`) 유지. 표는 `.operations-table` 공용. "출석 벌금 생성"·"투표 취소"·"거절"은 `.btn-destructive`.
- 비회장 세션 안내 화면은 패널 하나에 문구 + [회장 로그인].

### rules.html
- 보드 없음(공개 정적 페이지). 상단 요약표를 `.rows` 행 목록으로 바꾼다(항목 왼쪽, 금액 `.row-figure` 오른쪽, 기준은 `.row-sub`). 회칙 본문 패널은 유지. 경기 기록 섹션은 행 목록(날짜·구장 왼쪽, 스코어 오른쪽).
